# 🚀 Object-Oriented Programming (C++) - Semester 2 Portfolio

Welcome to my **Semester 2 Object-Oriented Programming (OOP)** repository. This repository serves as a complete portfolio of my journey learning C++, ranging from fundamental functional concepts to an advanced console-based project.

---

## 📂 Repository Structure

The repository is organized into the following logical sections:

* 📁 **Functions & Structures:** Early semester practice focusing on functional decomposition, procedural programming, structures (`struct`), and memory layout.
* 📁 **OOP Problems & Core Concepts:** Labs and assignments demonstrating core OOP pillars including:
  - Classes and Objects
  - Constructors & Destructors
  - Encapsulation & Abstraction
  - Inheritance (Single, Multiple, Hierarchical)
  - Polymorphism (Overloading and Overriding)
  - File Handling (ifstream/ofstream)
* 📁 **Food Delivery System (Main Semester Project):** A complete, console-based application simulating a real-world food ordering and management lifecycle.
* 🤐 **Project.zip:** A standalone archive containing the entire ready-to-run project for quick offline distribution.

---

## 🍔 Featured Project: Food Delivery System

The crown jewel of this repository is the **Food Delivery System**. It brings together all the OOP concepts learned throughout the semester into a practical terminal application.

### 🎮 Features Covered:
- **Dual Portal System:** Separate interfaces for **Customers** (to browse menus and place orders) and **Admins** (to update menus and manage active orders).
- **Persistent Storage:** Uses C++ File Handling to save restaurant menus and user histories even after the program closes.
- **Clean Architecture:** Modeled using strict OOP guidelines with modular classes.

### 🚀 How to Run the Project:
1. Open the **`Food Delivery System`** folder (either directly in this repo or after extracting `Project.zip`).
2. Locate the pre-compiled executable file (e.g., `main.exe` or `FoodDelivery.exe`).
3. **Double-click** the executable to run the console program instantly on Windows.
4. Follow the on-screen numeric prompts (`1`, `2`, `3` + `Enter`) to navigate the menus.

*Note: For a detailed step-by-step user guide, look inside the project folder for the `instructions.txt` file.*
